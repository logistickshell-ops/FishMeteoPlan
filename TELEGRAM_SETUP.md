# ФишМетеоПлан в Telegram Mini App — быстрый запуск

1. В `@BotFather` выполните `/newbot` и создайте бота.
2. Задеплойте проект на Render Static Site.
3. В `@BotFather` выполните `/newapp`, выберите бота и укажите HTTPS-адрес Render.
4. Для кнопки меню: `/mybots` → бот → `Bot Settings` → `Menu Button` → `Configure Menu Button`.
5. Откройте бота и запустите приложение.

Приложение корректно работает и в обычном браузере, и внутри Telegram. В Telegram автоматически вызываются `ready()` и `expand()`, а переключение вкладок использует haptic feedback, если он доступен.

Серверная валидация `initData` пока не требуется, потому что приложение не предоставляет защищённые пользовательские операции и хранит журнал локально. Не используйте `initDataUnsafe` как доказательство личности пользователя на backend без проверки подписи Telegram.
