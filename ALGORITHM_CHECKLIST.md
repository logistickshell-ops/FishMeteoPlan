# Чек-лист алгоритма прогноза клёва

## Архитектура

- [x] Асинхронный запрос Open-Meteo с текущими, часовыми и дневными данными.
- [x] Поиск города через Open-Meteo Geocoding API.
- [x] Детерминированный fallback при отсутствии API.
- [x] Нормализация каждого фактора в диапазон `[0, 1]`.
- [x] Чистая функция `calculateFishForecast()` без побочных эффектов.
- [x] Трассировка: факторы, reasoning, confidence breakdown и применённые эвристики возвращаются вместе с результатом.

## Формулы и границы

- [x] Температура воды: гауссова близость к оптимальному диапазону вида.
- [x] Давление: комфорт относительно диапазона вида.
- [x] Тренд давления: `1 - abs(delta_3h) / 3`, ограничение `[0, 1]`.
- [x] Ветер: отдельная нормализация скорости и учёт предпочтения наветренного/подветренного берега.
- [x] Луна: `1 - 2 * abs(phase - 0.5)`, результат `[0, 1]`.
- [x] Мутность, кислород, уровень воды, освещённость, кормовая база и тип водоёма нормализованы.
- [x] Сумма весов мирной и хищной модели равна `1.0`.
- [x] Результат ограничен `[0, 1]`, UI показывает его как 0–100%.
- [x] `NaN`/`Infinity` заменяются нейтральным значением `0.5` через `clamp()`.

## Эвристики

- [x] Эвристики применяются только при базовом score `[0.40, 0.60]`.
- [x] Суммарный сдвиг эвристик ограничен `[-0.12, +0.12]`.
- [x] Каждая применённая эвристика имеет имя, сдвиг, confidence и объяснение.
- [x] Эвристика не может перетянуть уже сильный научный сигнал.

## Confidence

- [x] Учитываются полнота входных данных, стабильность тренда, исторический prior и качество ответа API.
- [x] Confidence показывается пользователю отдельно от score.
- [x] Исторический компонент явно помечен как prior и не выдаётся за измеренную точность.

## Юридические и этические ограничения

- [x] В период `15 апреля — 1 июня` расчёт блокируется для выбранной даты.
- [x] В результате и интерфейсе присутствует юридический дисклеймер.
- [x] Нет утверждений о гарантированном клёве или научной точности без валидационного датасета.
- [x] Народные приметы не являются доминирующим фактором.
