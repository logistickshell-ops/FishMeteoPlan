# Региональные маяки ФишМетеоПлан

## Статус реализации

В проект добавлен файл `src/data/regionalBeacons.ts` с пятью объектами, по которым удалось собрать подтверждённые региональные сведения:

- Волга / Горьковское водохранилище у Ярославля;
- Которосль;
- Рыбинское водохранилище — ярославская часть;
- Угличское водохранилище — ярославская часть;
- Плещеево озеро.

Три остальных направления исследования не были включены на основании догадок: исследовательские ветки завершились из-за ограничения ресурсов. Это намеренное поведение — неполнота лучше фальшивого покрытия.

## Что такое маяк

Маяк — это **условие применения, источник и список нужных входов**, а не готовая поправка «прибавить 15 % к клёву». Каждый маяк содержит:

- тип водоёма;
- уровень доказательности;
- подтверждённые сведения;
- необходимые входы;
- условия применимости;
- ожидаемый выход: gate, контекст или кандидат-признак;
- ограничения и отсутствующие данные;
- URL источников.

## Принцип отсутствия фальши

В MVP отсутствующие гидрологические данные не заменяются погодой:

- температура воды из воздуха считается **модельной**, а не измеренной;
- DO, мутность и уровень не называются фактическими без наблюдения;
- пользовательские отчёты не превращаются в обучающие метки без усилия, нулевых выездов и проверки вида;
- исторические научные данные не переносятся на любую точку и текущую дату;
- правовой статус не используется как биологический сигнал;
- магнитный фактор удалён из отображаемых факторов;
- индекс не называется вероятностью улова и не имеет статистического доверительного интервала.

## Какие входы нужны для настоящего прогноза

Для будущей калиброванной модели нужно собирать неизменяемые snapshots погоды до выезда и завершённые журналы рыбалки:

- дата, UTC и исходный часовой пояс;
- точка/сегмент водоёма с privacy-округлением;
- тип водоёма;
- вид и подтверждение определения;
- берег/лодка, метод, класс снасти, наживка;
- число рыболовов, активных удилищ и часы ловли;
- нулевой результат или подтверждённый улов;
- уровень, расход, температура воды, DO, прозрачность/мутность с источником и QC;
- версия алгоритма, погодный model run и время выпуска прогноза.

До появления такого массива продукт показывает **индекс условий**, а не процент вероятности. Для нового водоёма или вида должна использоваться формулировка «данных недостаточно для калиброванной вероятности».
